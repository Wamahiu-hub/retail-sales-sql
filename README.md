# Retail Sales & Customer Intelligence Using PostgreSQL

**Company:** Duka Smart Electronics

## 📌 Project Overview
Establishment of the corporate PostgreSQL relational database, data ingestion, and execution of **46 analytical business questions** to deliver insights on customer lifetime value, category profitability, product performance, and monthly growth trends for Duka Smart Electronics.
